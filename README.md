# 💗 Lust Goddess — Калькулятор прокачки отношений

Неофициальный калькулятор для расчёта ресурсов (подарков), необходимых для прокачки отношений с легендарными бойцами в игре Lust Goddess.

🔗 Онлайн-версия: [https://dblpokojl.github.io/lust-goddess-relations-calculator/](https://dblpokojl.github.io/lust-goddess-relations-calculator/)

⚠️ Это неофициальный фан-проект. Все данные взяты из открытых источников и могут устареть после патчей игры.

## ✨ Возможности

- **Расчёт достижимого уровня** — укажи текущие баллы отношений и имеющиеся подарки, калькулятор покажет до какого уровня их хватит
- **Проверка контрольных точек** — мгновенно видно, хватает ли подарков до уровней 20 и 30 (где бойцы получают новые умения)
- **Учёт любимых подарков** — отметь чекбоксами любимые подарки бойца, калькулятор автоматически учтёт бонус +20% к баллам
- **Живой пересчёт** — никаких кнопок «Рассчитать»: результат обновляется по мере заполнения формы
- **Подсказка текущего уровня** — под полем с баллами показывается приблизительный текущий уровень отношений, чтобы можно было свериться с игрой

## Как пользоваться

### Сценарий 1: "До какого уровня хватит моих подарков?"

1. В блоке **Сейчас** введи суммарные баллы отношений с бойцом (как в колонке «Required total» таблицы отношений в игре)
2. В блоке **Подарки** укажи количество каждого типа подарков, которые есть в наличии
3. Отметь сердечками 💗 любимые подарки этого бойца (не обязательно по одному в каждой группе — сколько знаешь, столько и отмечай)
4. В блоке **Результат** посмотри достижимый уровень, остаток баллов и статус по уровням 20 и 30

### Сценарий 2: "Хватит ли мне подарков до уровня 20 / 30?"

1. Заполни блок **Сейчас** текущими баллами отношений
2. Укажи имеющиеся подарки и отметь любимые
3. Посмотри на майлстоуны:
   - ✅ **зелёный** — уровня хватит, и даже останется сколько-то баллов
   - ❌ **красный** — показано, сколько баллов не хватает до нужного уровня

### Сценарий 3: "Планирую закупку подарков — хватит ли на цель?"

1. Введи текущие баллы отношений
2. В блоке подарков укажи, сколько подарков планируешь купить/полутать
3. Отметь любимые подарки бойца
4. Проверь по майлстоунам, достижим ли нужный уровень

## 🧮 Механика отношений

В игре у каждого бойца есть параметр **отношения** с игроком:
- Всего **30 уровней** отношений
- Стартовый уровень = **1**
- Отношения могут только улучшаться
- Каждый следующий уровень требует больше баллов, чем предыдущий
- **Уровни 20 и 30** — ключевые: на них боец получает новые умения

### Подарки

Основной способ получить баллы отношений — дарить бойцам подарки. Всего 9 подарков в 3 группах по редкости:

| Группа | Базовые баллы | С любимым (+20%) |
|--------|---------------|------------------|
| Редкие (3 шт.) | +10 | +12 |
| Эпические (3 шт.) | +20 | +24 |
| Легендарные (3 шт.) | +50 | +60 |

### Любимые подарки

У каждого бойца в **каждой** группе подарков есть один **любимый**. Любимый подарок даёт бонус +20% к баллам:
- Редкий любимый: +12 вместо +10
- Эпический любимый: +24 вместо +20
- Легендарный любимый: +60 вместо +50
